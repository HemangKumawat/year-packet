## What it is (Hemang clarification 2026-09-17)

Not “ELN with git.” A coordination layer for **open-source / publicly funded labs**:

1. **Problem agenda (OpenDocket)** — which scientific problems deserve shared, public work next (evidence-gated; Gate *vetoes* unsourced cards).
2. **Open lab surface** — protocols, adapters, run records institutions can install.
3. **Decision trail** — why a problem was picked (citations, failed attempts, capacity, funding mandate).

Complements **Nightwatch** (`outputs/yc-f26/SUBMIT.md`): Nightwatch *runs* instruments; OpenDocket *chooses* what is worth running in the open.

## Grok shape pick

**Evidence-gated problem registry** first; federated org template = distribution; public RFP/bounty = later money pipe. White space vs protocols.io / OSF / Experiment.com / rasilab: nobody ranks *what next* for open+public funders together.
